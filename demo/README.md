# Demo dataset

Synthetic XRD scans for demos, screenshots and first-run exploration. **No real
lab data** — every pattern is generated by [`make_demo_data.py`](make_demo_data.py)
from a declared structure, so the set can live in a public repo alongside a
pending patent without leaking anything about real runs.

```bash
python3 demo/make_demo_data.py      # → demo/data/*.xy   (11 files)
python3 xrd_analyzer.py demo/data   # batch DG% table
python3 xrd_webgui.py --port 8642   # then open demo/data/ in the Analyze tab
```

`*.xy` is gitignored repo-wide, so `demo/data/` is **not committed** — the
generator is the artifact, and it is deterministic (fixed seed), so anyone
cloning the repo regenerates a byte-identical set.

## How a pattern is built

Each run is declared by the two quantities that physically define the (002)
complex: the graphitic d-spacing `d_g` and the turbostratic **area** fraction
`f_t`. The expected answer follows from Maire–Mering, so the demo set has a
ground truth to check the engine against:

```
d′ = (1 − f_t)·d_g + f_t·3.440        DG% = 100·(3.440 − d′) / 0.086
```

Bragg is inverted for both peak positions, the components are laid down as
OriginLab PsdVoigt1 shapes scaled to that area ratio, the (100)/(101)/(004)
carbon reflections are added on an air-scatter background, residual catalyst
phases go in for unwashed runs, and Poisson counting noise is applied last.

## The set

Filenames follow the lab's loose convention that `run_parser.py` already
understands (carbon source, Fe ratio, temperature, hold, wash state), so the
**Compare** tab can plot DG against temperature or hold time straight away.
These are catalyst-only runs — the published Fe baseline chemistry.

| File | d_g (Å) | f_t | Expected DG% | Engine reads |
|---|---|---|---|---|
| `GPC-raw-calcined.xy` | 3.4200 | 0.900 | — | **−40.6** (see below) |
| `GPC-6Fe-1000C-5h-washed.xy` | 3.3780 | 0.240 | 54.8 | 39.1 |
| `GPC-6Fe-1100C-5h-washed.xy` | 3.3670 | 0.150 | 72.2 | 64.3 |
| `GPC-6Fe-1200C-1h-washed.xy` | 3.3635 | 0.110 | 79.2 | 72.9 |
| `GPC-6Fe-1200C-3h-washed.xy` | 3.3600 | 0.075 | 86.0 | 83.0 |
| `GPC-6Fe-1200C-5h-washed.xy` | 3.3590 | 0.075 | 87.1 | 86.9 |
| `GPC-6Fe-1300C-5h-washed.xy` | 3.3570 | 0.040 | 92.7 | 93.0 |
| `GPC-6Fe-1400C-5h-washed.xy` | 3.3560 | 0.025 | 95.2 | 95.7 |
| `GPC-6Fe-1600C-24h-washed.xy` | 3.3552 | 0.014 | 97.2 | 97.4 |

Peak *height* rises with ordering as well as sharpening — scattering power spread
across a broad amorphous band in the feedstock concentrates into a narrow
reflection in the product — so the waterfall reads the way a real series does.

Above ~1200 °C the engine recovers the declared structure to a few tenths of a
percent. Below it the reported DG runs low, and that is not a generator
artifact: the turbostratic band is several degrees wide, so the 24–28.5° fit
window truncates it and the fitted area fraction comes out smaller than the
declared one. It is a real property of the NETL window, visible here because
this set has a ground truth to compare against.

## The three cases worth demoing

**`GPC-raw-calcined.xy` — the negative control.** Essentially all turbostratic,
d002 = 3.42 Å, well outside the graphitic peak bound. The two-peak fit has no
meaningful solution and DG comes back nonsensical (−40.6%). That is the honest
answer, and it is the whole argument for the **crystallinity index**: DG%
measures how *ordered* the carbon is, not how *much* graphite is present, so a
sample with almost no graphite in it has no meaningful DG at all.

**`GPC-6Fe-1300C-5h-unwashed.xy` — the data-quality flag.** Identical synthesis
to its `-washed` twin, plus residual Fe₃C and α-Fe lines. Every one of those
lines sits outside the fit window, so DG is unchanged (93.02 vs 92.98) while the
impurity scan reports *"Minor residual catalyst/carbonate present"* — Fe₃C at
43.78°, 9.7% of the (002) height. The flag tells you the acid wash was
incomplete without contaminating the number.

**`GPC-6Fe-1400C-5h-unwashed-offaxis.xy` — the internal standard.** The same
sample as `-1400C-5h-washed`, with the whole pattern shifted **+0.090°** to
simulate a specimen sitting off the focusing circle. Uncorrected it reads
**105.2%** — flatly unphysical. `calibrate_internal_standard()` indexes the
residual Fe₃C against its own lattice, agrees on **+0.0922°** across 6 lines
(spread 0.019°, above the 0.05° significance floor), and correcting brings it to
**92.19%** — against its correctly-mounted twin at **92.29%**. Residual catalyst
you would otherwise just wash away turns out to be a free 2θ reference.
